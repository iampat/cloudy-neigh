Chunked Columnar In-Memory Store: query.Table 1024 Rows per Chunk

To eliminate pointer bloat and GC overhead, rows are partitioned into 1024-element chunks. Vectors reside in dense, contiguous []float32 arrays. Modifying the table uses Copy-on-Write (CoW) structural sharing: only touched chunks are cloned, while untouched chunks share memory across revisions.

Memory Layout Invariants

  • Bitwise chunk math: chunk = row >> 10, offset = row & 1023.
  • No slice header per vector: 1024 vectors packed contiguously as 1024 * dim floats.
  • Bidirectional maps: vecToRow[c][vs] and rowToVec[c][rs] decouple rows from vectors.
  • Lock-free query serving: reads call atomic.Pointer[Table].Load() with zero lock contention.

Search Pipeline Optimization

  • Pre-filtering: Scalar equality checks run before SIMD vector distance.
  • SIMD Kernels: 4-way fused multiply-add (FMA) with horizontal pair addition.
  • Bounded Min-Heap: Candidates worse than the current top-k boundary are culled in $O(1)$.
  • Lazy Materialization: Protobuf records are deserialized only for final top-k hits.

Distributed Systems Failure Matrix & Recovery Invariants
Failure Scenario Impact Engine Recovery Protocol Safety Invariant
Crash during WAL Append HTTP request fails or truncates on object storage. Conditional write (Absent: true) ensures object is never overwritten. Caller retries at next sequence. Log contiguity: sequence numbers form an unbroken 1..N sequence.
Ingest Node Crash In-flight batch dropped before WAL acknowledgment. Process is stateless. Ingest client retries with standard exponential backoff against healthy replica. At-least-once delivery; mutations are idempotent.
Crash between Segment Upload and CAS Dangling unreferenced segment blob in segments/. On restart, Flusher re-tails WAL from checkpoint_seq + 1. Dangling segment is never added to manifest. Garbage-tolerant: segments become live only upon manifest CAS.
Manifest CAS Race (HTTP 412) Concurrent flusher updated branch manifest first. Flusher catches ErrPreconditionFailed, re-resolves current manifest, merges segment ref, retries CAS. Linearizable manifest progression on cloud storage.
Query Node Crash (kill -9) In-memory columnar table discarded. On restart, Query Engine polls refs/heads/, downloads segments, and reconstructs columnar table in RAM. Zero local disk durability requirement. Zero data loss.
